WorkFlow

Личный менеджер задач: канбан-доски и сведённый календарь нескольких Google-аккаунтов в одном окне.

Что это

Приложение для одного человека — его автора. Оно показывает задачи на канбан-досках и рядом с ними — события из подключённых календарей Google, чтобы planning и расписание не жили в двух разных вкладках. Регистрации, совместной работы и многопользовательского режима в нём нет и не планируется.

Доступ к Google Calendar

  • Список календарей аккаунта — только чтение.
  • События календаря — чтение, а также создание, изменение и удаление тех событий, которые пользователь заводит через приложение.

Других разрешений приложение не запрашивает.

Где живут данные

Приложение запускается пользователем на своём компьютере или собственном сервере. Данные хранятся в его базе, у автора приложения нет к ним доступа: сервиса, куда бы они отправлялись, не существует.

WorkFlow

A personal task manager: kanban boards next to a merged view of several Google Calendar accounts.

A single-user application, built by its author for their own use. It shows tasks on kanban boards alongside events from connected Google calendars. There is no sign-up, no collaboration and no multi-user mode.

It requests read access to the account's calendar list, and read/write access to calendar events so that events created in the app can be kept in sync. Nothing else.

The application runs on the user's own machine or server, and stores data in the user's own database. There is no hosted service the data is sent to.
