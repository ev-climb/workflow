# WorkFlow

Личный менеджер задач: канбан-доски плюс сведённый календарь нескольких Google-аккаунтов
в одном окне, с MCP-сервером для управления через Claude. Пользователь ровно один — я.
Многопользовательской логики в проекте нет и не будет.

## Команды

```bash
docker compose up -d db     # Postgres
pnpm dev                    # приложение на localhost:3000
pnpm typecheck              # tsc --noEmit
pnpm test                   # vitest, юнит-тесты сервисов
pnpm test:e2e               # playwright, дымовой сценарий
pnpm db:generate            # drizzle-kit generate после правки схемы
pnpm db:migrate             # накатить миграции
pnpm db:studio              # посмотреть данные глазами
pnpm auth:hash              # хеш пароля для APP_PASSWORD_HASH, пароль читается с stdin
pnpm mcp:stdio              # MCP-сервер поверх stdio, для Claude Desktop
```

## Стек

Next.js (App Router) · TypeScript strict · Postgres 16 · Drizzle ORM · Tailwind v4 ·
Radix UI (примитивы, не библиотека компонентов) · TanStack Query · dnd-kit · Zod ·
Vitest · Playwright · pnpm.

Обоснования — в `.docs/02-technical.md`, раздел 3. Не меняй выбор из этого списка,
не заведя ADR.

## Инварианты

Нарушение любого из них — баг, даже если тесты зелёные.

1. **Порядок карточек — только строковые дробные ранги** (`fractional-indexing`).
   Ни целых чисел, ни float. Перемещение карточки — ровно один `UPDATE` поля `rank`
   одной строки, независимо от размера колонки.
2. **Бизнес-логика живёт только в `src/server/services`.** Route handler, серверный
   компонент и MCP-инструмент делают три вещи: разбирают вход, зовут сервис,
   сериализуют ответ. Логика в компоненте или в обработчике маршрута — переписывать.
3. **Время в базе — `timestamptz` в UTC.** Отрисовка в `Europe/Moscow`. События «на весь
   день» хранятся как `date` с флагом `all_day` и **никогда** не проходят через
   конвертацию часового пояса — иначе уезжают на сутки.
4. **Идентификаторы Google — не первичные ключи.** У каждой сущности свой `id`, а
   `google_event_id` / `google_calendar_id` — обычные поля с индексом.
5. **Удаление мягкое.** `archived_at`, а не `DELETE`. Физически чистит только отдельная
   команда обслуживания.
6. **Секреты не попадают в репозиторий.** Refresh-токены Google лежат в базе
   зашифрованными ключом из `APP_ENCRYPTION_KEY`. В `.env.example` — только имена
   переменных и комментарии.
7. **Никаких путей вида `/home/...` в коде и конфигах.** Всё через переменные окружения:
   проект должен переехать на VPS без правок исходников.

## Как мы работаем

- **Одна фаза за раз.** Задание на фазу — в `.docs/phases/`. Не забегай вперёд: код
  «на будущее» для фазы, до которой мы не дошли, не пишем.
- **После каждой законченной задачи — запись в журнал** через
  `.docs/scripts/docs-log.sh`. Файлы журнала не открывай ни `Read`, ни `cat` — они
  большие; точечный поиск через `rg`.
- **Изменилось решение — правь документ. Изменилась только реализация — не правь.**
  Проверка: человек, прочитавший документ вчера, сегодня будет действовать неправильно?
- **Решение переживёт полгода — заводи ADR.** Существующие ADR не переписываются:
  отменённому ставится статус, новое пишется отдельным файлом.
- **Схему БД, эндпоинты и переменные окружения в документы не копируем** — источник
  истины код, в документах ссылка на файл.
- Миграции только через `pnpm db:generate`, руками SQL не пишем.
- Новая зависимость — только с причиной, записанной в журнал. Если тянет за собой
  больше трёх пакетов, сначала спроси.

## Соглашения

- Идентификаторы, имена файлов и веток — английские; комментарии, коммиты и документы —
  русские.
- Коммит: императив, первая строка до 72 символов, без точки. `добавить перенос карточки
  между списками`, а не `добавлен перенос`.
- Файлы компонентов — `PascalCase.tsx`, всё остальное — `kebab-case.ts`.
- Сервис возвращает данные или бросает типизированную ошибку; HTTP-коды выбирает
  route handler, а не сервис.
- Тесты пишем на сервисы и на маппинг событий Google. Компоненты юнит-тестами не
  покрываем — вместо этого один дымовой сценарий Playwright.

## Чего не делаем

Скоуп зафиксирован в `.docs/01-product.md`, раздел 5. Коротко: ни совместной работы, ни
прав доступа, ни комментариев, ни ленты активности, ни уведомлений, ни шаблонов досок,
ни автоматизаций, ни Гантта, ни мобильного приложения. Если задача звучит как что-то из
этого списка — останавливайся и спрашивай, а не реализуй.
